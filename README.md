# Fraud Detection ML Service

ML-сервис для выявления подозрительных карточных транзакций.
Проект включает исследование данных, обучение модели, подбор порога,
HTTP API и автоматические тесты.

**Стек:** Python, pandas, scikit-learn, FastAPI, Pydantic, pytest, uv.

## Как работает

`POST /predict` принимает одну транзакцию с признаками: `Time`, `V1`–`V28`, `Amount`.
API проверяет запрос и передаёт признаки в `PredictionService`.
Сохранённый Random Forest оценивает риск мошенничества.
При оценке не ниже порога `0.17` транзакция помечается как подозрительная.

Пример ответа:

```json
{
  "risk_score": 0.28,
  "is_suspicious": true
}
```

Сервис и модель кешируются между запросами в рамках одного процесса.
Обучение выполняется отдельно в ноутбуке.

## Результаты модели

Используется [Credit Card Fraud Detection от ULB](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
После удаления точных дубликатов данные разделены в исходном порядке
на train / validation / test в пропорции 70 / 15 / 15.
Логистическая регрессия и Random Forest обучены и оценены на одинаковом
разделении данных. Для регрессии масштабирование обучается только на train;
случайный лес используется без масштабирования.

Критерий выбора — максимальный Recall при Precision не ниже 80% на validation.
Для каждой модели порог подбирается отдельно по сетке от 0.01 до 0.99 с шагом 0.01.
Это учебное условие эксперимента.

Сравнение на validation:

| Модель | Порог | Average Precision (AP) | Precision | Recall |
|---|---:|---:|---:|---:|
| Logistic Regression | 0.52 | 0.774 | 80,0% | 50,9% |
| Random Forest | 0.17 | 0.857 | 81,8% | 81,8% |

Для API выбран **Random Forest**: при выполнении ограничения на Precision
он обнаружил 45 из 55 мошеннических операций против 28 у регрессии.

Результаты выбранной модели на test при фиксированном пороге `0.17`:

| Показатель | Результат |
|---|---:|
| Average Precision (AP) | 0.736 |
| Precision | 74,5% |
| Recall | 73,1% |
| Обнаружено мошеннических операций | 38 из 52 |
| Пропущено мошеннических операций | 14 |
| Ложных тревог | 13 из 42 507 обычных операций |


Признаки `V1`–`V28` анонимизированы с помощью PCA. Сервис работает с этим
форматом данных.

## Запуск

Требуется Python 3.12 или новее. Все команды выполняются из корня проекта.

```bash
uv sync
mkdir -p data artifacts
```

Датасет и обученная модель не хранятся в репозитории. Чтобы получить модель:

1. Скачайте датасет по ссылке выше и поместите `creditcard.csv` в `data/`.
2. Откройте ноутбуки в IDE с поддержкой Jupyter.
3. Последовательно выполните `notebooks/01_eda.ipynb`, `notebooks/02_baseline.ipynb` и `notebooks/03_random_forest.ipynb`.
4. Убедитесь, что создан `artifacts/random_forest_model.joblib` — модель и порог для API. Baseline сохраняется отдельно в `artifacts/baseline_model.joblib`.

Запустите API:

```bash
uv run uvicorn app:app --reload
```

Откройте [Swagger UI](http://127.0.0.1:8000/docs), выберите `POST /predict`
и отправьте признаки транзакции без поля `Class`.
Запрос без обязательного поля возвращает `422`.
