# Fraud Detection ML Service

ML-сервис для выявления подозрительных карточных транзакций.
Проект включает исследование данных, обучение модели, подбор порога,
HTTP API и автоматические тесты.

**Стек:** Python, pandas, scikit-learn, FastAPI, Pydantic, pytest, uv.

## Как работает

`POST /predict` принимает одну транзакцию с признаками: `Time`, `V1`–`V28`, `Amount`.
API проверяет запрос и передаёт признаки в `PredictionService`.
Сохранённый pipeline выполняет масштабирование и предсказание логистической
регрессии. Оценка сравнивается с порогом `0.1`.

Пример ответа:

```json
{
  "risk_score": 0.28,
  "is_suspicious": true
}
```

Сервис и модель кешируются между запросами в рамках одного процесса.
Обучение выполняется отдельно в ноутбуке.

## Результаты модели

Используется [Credit Card Fraud Detection от ULB](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
После удаления точных дубликатов данные разделены в исходном порядке
на train / validation / test в пропорции 70 / 15 / 15.
Масштабирование обучается только на train, порог выбран на validation.

На test при фиксированном пороге `0.1`:

| Показатель | Результат |
|---|---:|
| Precision | 66% |
| Recall | 63,5% |
| Обнаружено мошеннических операций | 33 из 52 |
| Пропущено мошеннических операций | 19 |
| Ложных тревог | 17 из 42 507 обычных операций |

Признаки `V1`–`V28` анонимизированы с помощью PCA. Сервис работает с этим
форматом данных.

## Запуск

Все команды выполняются из корня проекта.

```bash
uv sync
mkdir -p data artifacts
```

Датасет и обученная модель не хранятся в репозитории. Чтобы получить модель:

1. Скачайте датасет по ссылке выше и поместите `creditcard.csv` в `data/`.
2. Откройте ноутбуки в IDE с поддержкой Jupyter.
3. Последовательно выполните `notebooks/01_eda.ipynb`, затем `notebooks/02_baseline.ipynb`.
4. Убедитесь, что создан `artifacts/baseline_model.joblib`.

Запустите API:

```bash
uv run uvicorn app:app --reload
```

Откройте [Swagger UI](http://127.0.0.1:8000/docs), выберите `POST /predict`
и отправьте признаки транзакции без поля `Class`.
Запрос без обязательного поля возвращает `422`.
